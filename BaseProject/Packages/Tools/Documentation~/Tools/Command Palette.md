# Command Palette

🪛 **Tool** · for everyone

**Menu:** `Tools > Base Packages > Command Palette`

**Shortcut:** `Ctrl + Shift + K` (`Cmd + Shift + K` on Mac), or the palette button in the main toolbar

One search box for every menu item, every "Create" entry and every settings page, Unity's own included. The fastest way to reach any tool without remembering where it lives.

## How to use it

1. Press the shortcut.
2. Type part of what you are looking for. Typos and partial words are fine.
3. Press **Enter** to run the top result, or use the arrow keys to pick another one.

## Narrowing the search

| Start with | To search only |
| --- | --- |
| `>` | Menu items |
| `+` | Asset creation entries |
| `@` | Project Settings and Preferences pages |
| `#` | Entries with a tag |

## Good to know

- Things you use often and things you pinned rank higher.
- Settings pages from the project and its packages are listed. Unity's own settings pages are not; use Unity Search with `set:` for those.
- The shortcut can be changed in `Edit > Shortcuts` under **Base > Command Palette**.
