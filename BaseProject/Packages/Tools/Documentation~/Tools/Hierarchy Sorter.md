# Hierarchy Sorter

🪛 **Tool** · for everyone

**Tags:** #artist #designer #workflow #scenes

**Menu:**

- `GameObject > Base > Sort Children Alphabetically`
- `GameObject > Base > Sort Active Scene Alphabetically`

Sorts the hierarchy by name, recursively.

## How to use it

**One object:** select a GameObject and run **Sort Children Alphabetically**. All of its children, and their children, are sorted.

**Whole scene:** run **Sort Active Scene Alphabetically**. Root objects are sorted too.

## Notes

- Both actions are undoable with Ctrl+Z.
- The scene is marked dirty, so remember to save.
- Sorting only changes sibling order. Nothing is reparented, moved or renamed.
