# Execution Order Overview

🔧 **Tool** · programmers only

**Menu:** `Tools > Base Packages > Code > Health > Execution Order Overview`

Lists every script with a custom execution order, sorted by the order that actually wins at runtime. Handy when script order matters and you need to see the whole picture instead of one entry at a time.

## How to use it

1. Open the window.
2. Search for a script by name.
3. Click a row to open that script.

## Toolbar options

| Option | Meaning |
| --- | --- |
| Search | Filter by script name. |
| Include External | Show Unity and package scripts too. |
| Sort direction | Ascending or descending order. |

Badges tell you where a script comes from: `pkg` for a package, `lib` for built into Unity, nothing for your own project.
