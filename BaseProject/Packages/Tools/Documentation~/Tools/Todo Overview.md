# Todo Overview

🔧 **Tool** · programmers only

**Tags:** #programmer #project-health

**Menu:** `Tools > Base Packages > Code > Health > Todo Overview`

**Settings:** `Project Settings > Base Tools > Todo Overview`

Lists every `TODO`, `FIXME`, `BUG`, `HACK` and similar note in the project's code, with owner and date if the note has them.

## How to use it

1. Open the window. Press **Refresh** to scan again after changes.
2. Search, or filter by keyword, owner and date.
3. Split the list into sections with the group option.
4. Double click a row to open the file at that line. **Copy** copies the full note.

## Dates

A project decides what a date in a note means: a **deadline** or **when it was written**. With deadlines, old notes show as overdue. With written dates, old notes show as stale. A single note can say which one it means for itself.

## Settings

The keywords to look for, how owner and date are written in a note, and which folders to skip are set in Project Settings. They are saved in `ProjectSettings`, so the whole team searches for the same things.
