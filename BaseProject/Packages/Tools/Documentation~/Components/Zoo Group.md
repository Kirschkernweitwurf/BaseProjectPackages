# Zoo Group

🗞️ **Component** · programmers only

**Tags:** #programmer #assets

One block of a built zoo, with the name, color and size the Scene view draws its zone from.

## What you need to know

- You never add this yourself. It is hidden from the Add Component menu.
- It does nothing at runtime.
- The name links it to its group in the [💌 Zoo Config](../Scriptable%20Objects/Zoo%20Config.md).
