# Components

Scripts you drop onto a GameObject in a scene.

| Component | What it does |
| --- | --- |
| [🔖 LightingProfileApplier](lighting-profile-applier.md) | Applies a saved lighting setup when the scene loads. |
| [🗞️ Zoo Root Marker](zoo-root-marker.md) | Internal marker used by the Asset Zoo Builder. You never add this yourself. |
