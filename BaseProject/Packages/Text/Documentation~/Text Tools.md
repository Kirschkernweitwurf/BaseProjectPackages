# Text Tools

🧰 **Tools** · menu items and editor windows

**Tags:** #localization #ui

Editor windows in the Text package. They live under **Tools > Base Packages > Assets > Localization**.

## Localization

| Tool | What it does |
| --- | --- |
| [🪛 Text Fit](Tools/Text%20Fit.md) | Renders every localized text in every language in its real box and lists the ones that do not fit. |

Menu paths are defaults. They can be moved with the Menu Item Manager in the Tools package, so your project may differ.
