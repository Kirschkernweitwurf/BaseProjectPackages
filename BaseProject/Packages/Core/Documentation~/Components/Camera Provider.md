# Camera Provider

🗞️ **Component** · programmers only

**Tags:** #programmer

Gives code fast access to the main camera without looking it up by tag every frame.

**Add it:** Inspector › **Add Component** › search `Camera Provider`.

## How to use it

1. Put it on one of the manager prefabs, once. You rarely add it to a scene yourself.

## Fields

None. Add it and it works.
