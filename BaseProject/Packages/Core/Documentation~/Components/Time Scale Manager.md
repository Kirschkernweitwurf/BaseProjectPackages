# Time Scale Manager

🗞️ **Component** · programmers only

**Tags:** #programmer #menus

Decides the game speed. Menus and gameplay request a time scale with a priority; the highest request wins, and normal speed applies when nobody asks.

**Add it:** Inspector › **Add Component** › search `Time Scale Manager`.

## How to use it

1. Put it on one of the manager prefabs, once. You rarely add it to a scene yourself.

## Fields

None. Add it and it works.
