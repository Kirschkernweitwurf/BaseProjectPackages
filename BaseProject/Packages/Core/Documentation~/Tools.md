# Tools

🧰 **Tools** · menu items and editor windows

Editor windows in the Core package.

| Page | What it does |
| --- | --- |
| [🪛 Regenerate Menu Identifiers](Tools/Regenerate%20Menu%20Identifiers.md) | Rebuilds the menu identifier registry and its generated code. Runs automatically, manual is for when things look out of sync. |
| [🔧 Event Bus Window](Tools/Event%20Bus%20Window.md) | Shows every event type and its subscribers while the game runs |
| [🔧 State Machine Monitor](Tools/State%20Machine%20Monitor.md) | Shows the running state machines, their current state and the transitions being checked |

> [!NOTE]
> Menu paths are defaults. They can be moved with the Menu Item Manager from the Tools package.
