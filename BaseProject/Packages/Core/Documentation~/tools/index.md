# Tools

Editor windows in the Core package.

| Page | What it does |
| --- | --- |
| [🪛 Regenerate Menu Identifiers](regenerate-menu-identifiers.md) | Rebuilds the menu identifier registry and its generated code. Runs automatically, manual is for when things look out of sync. |
| [🔧 Event Bus Window](event-bus-window.md) | Shows every event type and its subscribers while the game runs |
| [🔧 State Machine Monitor](state-machine-monitor.md) | Shows the running state machines, their current state and the transitions being checked |

> [!NOTE]
> Menu paths are defaults. They can be moved with the Menu Item Manager from the Tools package.
