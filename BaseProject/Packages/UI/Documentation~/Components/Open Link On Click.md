# Open Link On Click

🔖 **Component** · for everyone

**Tags:** #designer #artist #ui

Opens a website in the player's browser when the button is clicked. Good for credits, socials or a support page.

## Where to put it

On a GameObject that has a **Button** component.

## Fields

| Field | Required | What it does |
| --- | --- | --- |
| URL | Yes | The full web address, including `https://`. |

## Good to know

- Always write the full address. `example.com` will not work, `https://example.com` will.
- On desktop this opens the default browser. In a web build it opens a new tab.
