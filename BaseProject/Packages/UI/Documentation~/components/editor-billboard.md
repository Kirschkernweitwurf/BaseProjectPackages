# Editor Billboard

Same idea as [🪛 Billboard](billboard.md), but it also turns while you are working in the Scene view. Handy for placing signs or labels and seeing right away how they read.

## Where to put it

On the object that should turn. Only one per object.

## Fields

None.

## Good to know

- It always faces the camera directly and cannot be locked upright. If you need upright objects in the final game, use [🪛 Billboard](billboard.md) instead.
- Because it turns the object in the Scene view too, the rotation you see saved in the prefab may differ from what you set by hand. That is expected.
